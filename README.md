# Paradise Nursery

Course project source for the React final project: a houseplant store with landing page, 18 plants in three categories, Redux cart, live quantities/totals, add/disable, increment/decrement/delete and a Coming Soon checkout.

## Run

```sh
npm install
npm run dev
npm run build
```

Uses local original SVG illustrations; no external image services. Cart is session-only. Prices are sample USD prices. No payment processing.
